## 🚀 Featured Projects

### 💊 Pharma Procurement Intelligence — Gemini Extraction & QLoRA
> Turns messy, OCR-corrupted GeM/NIC pharmaceutical tenders into clean, analysis-ready data.

`Gemini 2.5 Flash` · `Qwen` · `QLoRA` · `PEFT` · `Context Caching` · `FastAPI` · `PostgreSQL`

- 🧠 ~44K-token domain-engineered prompt with batched parallel inference and explicit context caching
- 🛡️ Deterministic regex layer validates every output — strengths are never invented
- 🔗 Self-growing canonical maps (153K product descriptions, 11K brands, 5K bidders) for entity resolution
- 🔬 Cleaned data trains a QLoRA-fine-tuned Qwen model that runs locally as a low-cost alternative to the API
- 📊 Processed **10M+ procurement records**, served via a crash-resilient FastAPI service with an audit trail

### 🏢 AI Company Intelligence Engine
> Give it a company name, get a verified profile — with the source and confidence of every field.

`Python` · `Gemini` · `DeepInfra` · `RAG` · `Serper / Tavily` · `SQLite` · `Ollama`

- 🔎 Researches across web search, Gemini grounded search, MCA register and GST sources
- 🧾 Outputs CIN, GST/PAN, directors, address, website, contact and status
- 🧩 Entity resolution maps many typed spellings to one company, with register cross-checks
- ✅ Unverified values are left blank rather than guessed; results are cached so no company is researched twice
- 📈 **28K+ records enriched**

### 📞 AI Call Agent — n8n + Retell
> Production voice-calling agent for outreach, feedback and inquiries.

`Retell AI` · `n8n` · `Voice AI` · `Webhooks` · `CRM Sync`

- 🎙️ Inbound & outbound calls with real-time conversational speech
- 🔁 Active/inactive user outreach, feedback collection and inquiry routing
- 🗂️ Dynamic response logic, CRM updates and post-call data sync — fully automated end-to-end

### 🔗 n8n Lead-Gen Automation
